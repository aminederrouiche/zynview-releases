# ZynView releases

Download the latest ZynView APK for Android:

**https://github.com/aminederrouiche/zynview-releases/releases/latest/download/zynview.apk**

Each release also has a `zynview.apk.sha256` checksum and a `release.json` with the version. Requires Android 10 or newer on a 64-bit (arm64) phone. Read the installation guide on https://zynview.com before installing.

This repository only hosts release files.
